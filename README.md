This SwiftUI app helps you keep a food diary by tracking the meals and drinks you consume. You can add, view, and delete entries to maintain a healthy lifestyle. 🍏

## Features

- ✅ Entries for different categories: meals, snacks, drinks, desserts  
- ✅ Simple list view with expandable sections  
- ✅ Detail view for each entry showing additional info like calories, date, mood, and favorite status  
- ✅ Add new entries via a sheet  
- ✅ Swipe to delete individual entries  
- ✅ Delete all entries at once with confirmation alert  
- ✅ Navigation using NavigationStack and NavigationLink  
- ✅ Use of SwiftUI elements like List, Section, Alert, Sheet, Button, and Bindings  

## Technologies

- SwiftUI  
- NavigationStack & NavigationLink  
- @State and @Binding for state management  
- List and Section with expandable sections  
- Alerts and Sheets for user interaction  
- SwipeActions for deleting entries  

## How to Run

1. Click the green **"Code"** button on this repository and select **"Open with Xcode"** (if available), or download the ZIP and open the project manually.  
2. Alternatively, open the `.xcodeproj` or `.xcworkspace` file directly in **Xcode**.  
3. Click the **Run** ▶️ button in the top toolbar to build and launch the app in the iOS Simulator or on a physical device.  
4. Use the app to track meals and drinks, add new entries, view details, and delete entries.
